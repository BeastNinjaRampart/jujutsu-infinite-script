# Jujutsu Infinite Script

Download: soon

Jujutsu Infinite farming script inside NexusLoader.

## Functions

- auto farm curses with level filter
- auto mission accept
- chest and domain finder
- auto boss
- auto stat allocation
- fast respawn

## Steps

1. Download and extract, run the exe as admin
2. Open Jujutsu Infinite
3. Attach, select the script, Run

## Settings

| Option | Default |
| --- | --- |
| level filter | +0 |
| boss farm | on |
| chest finder | on |
| build | strength |

## Notes

Domain events pause the farm. Private server recommended for long sessions.

Windows 10/11. The script comes inside the loader.
